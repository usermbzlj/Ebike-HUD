# 已知限制、数据范围与风险

## 产品定位

实验性辅助感知。未知、遮挡或跟踪失效时必须显示「不可观测 / 感知受限」，不得把「未检测到」解释为「道路安全」。

## V0.1 明确不做

- 不控制车辆，不建议左转/右转，不输出制动指令
- 不承诺暴雨、完全无照明、积水覆盖坑底、镜头水滴时可靠识别
- 不追求厘米级坑深；距离为带置信度的近似值
- 不以行人、车辆（除遮挡）、交通灯、标志、车道级导航为主任务
- 不保证其它 Android 机型、其它支架位置或其它车辆直接可用
- ARCore 不是核心链路单点依赖

## 识别距离边界

首次稳定识别门槛只针对**中大型、视觉可见**异常：

- 白天中位数 ≥ 15 m（目标 20 m）
- 有路灯夜间中位数 ≥ 12 m（目标 15 m）

被前车完全遮挡、严重逆光、积水覆盖、连续严重模糊或镜头水滴应验收为「正确识别不可观测并降级」。

## 当前引擎

出厂模型包 `heuristic-cv-0.1.0` 是双尺度经典视觉，用于打通闭环与回归，**不是**场测发布用的量化分割网络。`roadseg-synth-0.1.0`（若已导出）是合成 classmap 上训练的轻量卷积 sidecar：桌面用 numpy 双尺度头，Android LiteRT 对远/近 ROI 各跑一次再贴回整帧。混合引擎保留启发式实例属性；空图不得清空 HUD。这仍不是 PKC110 真值训练的量化分割网。

桌面可选用 YOLOPv2 ONNX（`models/yolopv2/YOLOPv2.onnx`，约 156 MB，不入库）作为**可行驶区域 + 车辆遮挡** sidecar。权重来自 BDD 风格驾驶场景，输入 640 动态 letterbox，在 CPU 上跑。它**不是**坑洞/井盖/减速带检测器，也不是 PKC110 上的 LiteRT 包；空输出不得清空 HUD。

桌面颠簸三类改走 **YOLO-World** 开集检测（`models/yolo-world/yolov8m-worldv2.pt`，不入库），提示词仅为大坑 / 减速带 / 下沉井盖，可用 `Video/train/inbox` 自采微调。推理成功（含本帧 0 框）会清掉启发式坑/带/盖，避免斑马线/反光假阳性；仅当大模型加载或推理抛错时才回退启发式。可行驶区域绿填会在颠簸轮廓处挖空。手机端 `rpar export-bump-tflite` 在 Windows 上导出 ONNX（Ultralytics LiteRT 仅 Linux/macOS），由 ONNX Runtime 跑同一套框；这仍不是 PKC110 真值训练的量化实例网，也未在真机上证明 p95 ≤150 ms。

桌面黄金回归使用合成道路（已知距离与方位），用来锁住跟踪、门控、几何与提醒策略；不能替代 PKC110 实路 10 h 误提醒统计。

夜间路面噪声、尾灯纹理不得被标成 `rough_broken`。启发式不再用「路上相对最糙的 8%」当破损；低照/眩光下该类检测关闭。研究模式也不再把未确认的 TRACKED 画成实线标签；**未确认的大坑/下沉井盖/减速带可以用虚线橙红显示**（语音仍须 CONFIRMED）。YOLOPv2 只负责可行驶区域和车辆遮挡；车辆框用灰紫，避免被看成颠簸预警。前车占画面约 8% 只把 HUD 标成「前方道路被遮挡」，不再冻结路边颠簸跟踪；被车辆多边形盖住的实例仍丢弃。

`Video/` 里的实拍片段按时长对齐规格附录样本（约 68.8 s 白天、约 55.0 s 夜间）。当前文件是 960×540 / 1280×720 @30 fps 转码，不是 PKC110 Camera2 1080p60 SDR 分析流。

能力探测会按 Camera2 最小帧时长列出 30/60 候选，并用 YUV 时间戳中位数报实测 FPS。16.67 ms 时长不再截断成 59 fps。PKC110 上的成功组合、实测帧率和 60 min 热稳定仍须在真机点「能力探测」后写入 `capability_report.json`。

公开路面病害数据（摩托视角坑、远距小坑、井盖、夜间驾驶分割等）只作预训练/教师/hard negative 参考，不能替代 PKC110 自采 session，也不能直接拼成一个检测类别表。见 `docs/DATASETS.md`。

手机可将 `models/roadseg-field-0.1.0/seg_weights.json` 作为双尺度道路/遮挡 sidecar（YOLOPv2 教师蒸馏，不是坑洞网）。无该文件时保持启发式道路兜底。

M5 冲击接口会把已确认对象对齐到预计压过时刻附近的 IMU 垂向峰值，并在合成世界上证明起伏几何的峰值高于平整补丁。这不是已训练的冲击网络，也不是 PKC110 实车压过标签；未验证前不得用于提醒。

## 主要风险（摘自规格第 13 章）

| 风险 | 缓解 |
| --- | --- |
| 支架无减震 | 先做物理减震 A/B；质量门控；短曝光 |
| 夜间泛光与时域降噪 | SDR 统一输入；局部可见性；hard negative |
| 车把偏转 ≠ 车辆轨迹 | 标定 + 走廊 + IMU，禁止屏幕三等分 |
| 前车/积水不可观测 | 遮挡多边形内的实例丢弃并暂停非颠簸语音；路边大坑仍可跟踪 |
| 热与功耗 | 先降远处 ROI / 模型频率，最后才降预览 |
| 信息过载 | 骑行模式标签限额、触摸锁、声音可关 |

## 待用户补充（不阻塞 M0–M3）

- 电动车具体型号、轮径、悬挂（冲击模型前必须确认）
- 支架减震方案
- 镜头膜/油膜状态
- RTX 5070 实际显存（训练脚本按显存自适应，不写死）
