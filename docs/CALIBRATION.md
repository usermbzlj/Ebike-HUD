# 安装与标定指南

V0.1 只保证 **Find X8 Pro + 固定左侧车把安装位**。支架位置、减震或俯仰变化后必须新建配置档。

## 安装配置档（CAL-001）

绑定并保存：

- 支架位置、横屏方向、主摄 ID
- 相机高度、俯仰、横滚
- 相对车辆中线偏移（左把为负）
- 中立车把朝向
- 地平线、车辆中心线、近端参考点

配置可命名、导出、恢复。`mount_profile_id` 与 `calibration_hash` 写入每一段会话。

默认档：`left_handlebar_v1`。

## 引导式静态标定（CAL-002）

目标 3 分钟内完成：

1. 车辆直立，车把回正，对准平直道路。
2. 确认地平线（研究模式辅助线）。
3. 确认车辆中心线（不是画面中线；左把安装必须补偿）。
4. 点选近端参考点（约 3 m 路面标记）。
5. 保存标定图与参数。

未选择有效配置时，应用**禁止显示精确距离**，只保留近/中/远或方位。

## 已知距离校准（CAL-003）

在平路放置 5 m、10 m、20 m 地面标记，修正姿态与距离模型。验收：

- 5–15 m MAE ≤ 2.5 m
- 15–30 m MAE ≤ 5 m

## 启动健康检查（CAL-004）

每次启动比较地平线、消失点、静止姿态与配置。偏差超过可配置阈值时提示重新标定，并隐藏精确米数。

## 物理减震 A/B（CAL-006）

无减震支架会造成曝光期内纹理丢失，软件无法恢复。用研究模式对比：

- 模糊帧占比
- 角速度峰值
- 模型可用帧率

不要用主观观感代替这三项统计。

## 桌面默认外参（无实机时）

`rpar` 模拟器使用：高度 1.12 m、俯仰 18°、左偏 0.32 m、约 68° 水平视场。真机必须用 Camera2 内参与实拍标定覆盖这些值。
