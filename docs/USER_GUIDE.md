# 用户操作说明

本系统是实验性辅助感知工具。骑行时必须自己观察道路。系统不提供转向、避让或制动指令。

## 骑行模式（默认）

1. 将 Find X8 Pro **横屏**固定在**左侧车把**，使用后置 1× 主摄。
2. 打开应用，确认状态为「感知正常」或可读的降级文案。
3. 顶部显示速度与必要告警；路面异常用轮廓表示，详细文字标签最多 5 个。
4. 开始骑行后进入触摸锁。解锁需长按。紧急停止采集始终可用。
5. 声音提醒默认简短（左前方 / 正前方 / 右前方 + 类型），可在设置中完全关闭。关闭后 AR 与记录仍完整。

状态文案：

| 状态 | 骑行模式文案 |
| --- | --- |
| 正常 | 感知正常 |
| 轻度受限 | 可见性下降 |
| 严重模糊 | 画面模糊，短时续接 |
| 遮挡 | 前方道路被遮挡 |
| 镜头水滴 | 请在安全处清洁镜头 |
| 过热 | 性能降级 |
| 存储不足 | 存储空间不足，即将停止录像 |

## 研究模式

停车后切换。显示全部候选、track_id、类别、置信度、距离、TTC、可见性、后端和性能。可叠加道路 / 遮挡 / 可见性热图与行驶走廊。用于复盘，不建议骑行中操作。

## 三种运行配置

- **仅采集**：Camera2 + IMU + 分段录像，不开模型（安全模式也可只验证采集器）。
- **实时感知**：采集 + 推理 + AR。
- **实时感知 + 全量记录**：额外写入观测、轨迹、提醒决策快照和诊断。

启动前会按约 25 Mbps 估算剩余可录时长（1 h ≈ 11.25 GB）。空间不足时禁止开始或改用无视频轻量记录。

## 声音提醒

- 独立开关，默认高阈值。
- 正常井盖、平整修补、远离行驶走廊的对象默认不播报。
- 同一目标默认只提醒一次；全局冷却建议 ≥ 2 秒。
- 设置页可试听左 / 正 / 右提示。支持扬声器与蓝牙耳机。

## 数据导出

设置 → 导出会话。确认页列出将包含的数据类型（视频分段、IMU、位置、模型输出、道路/遮挡掩膜、诊断）。大于约 512 MB 时自动拆成 `.partNN.zip` 分卷。导出必须由你显式触发。分享版可另选车牌/人脸模糊；原始包不会自动上传。

桌面可把误提醒与手动标记收成错误案例库：

```text
rpar error-lib session_... --out artifacts/error_lib
```

## 桌面回放

把 `session_*` 目录拷到电脑后：

```text
rpar verify session_...
rpar report session_...
rpar serve
```

研究控制台可同步看画面、质量分数、对象轨迹和提醒决策，用于解释「为什么这一帧没有推理 / 没有提醒」。
